# HOMLY · материалы перед реальным запуском

Сейчас репозиторий содержит готовый фронтенд-прототип, а не подключённый магазин. Ниже только данные, без которых нельзя публиковать рабочую торговую версию.

## Что нужно от владельцев бренда

- [ ] Подтвердить **ассортимент**, названия, категории и наличие наборов. Товары в `app.js` сейчас демонстрационные.
- [ ] Добавить **свои фотографии**. Минимум: 1 атмосферное фото для первого экрана, 1 процесс, 1 коробка/упаковка, по 3–5 фото каждого товара. Лучше загрузить в `assets/products/` в WebP/JPG.
- [ ] Указать реальные **цены, размеры готовых изделий, материалы и содержимое набора**. Не использовать текущие тестовые цены для продаж.
- [ ] Дать **контакты HOMLY**: Instagram, Telegram или email (что действительно будете обслуживать).
- [ ] Решить, как принимать заказы: платёжная система, доставка, возвраты и документы магазина.

## Что нужно сделать на GitHub один раз

Перейти в **Settings → Pages → Build and deployment → Source: GitHub Actions**.

После этого workflow `HOMLY preview` сможет разместить страницу по адресу `https://anastasia2627.github.io/homly/`. Пока Pages не включён, действия `configure-pages` падают с `Not Found`.

## Примечание

Пока оплата, отправка заказа и сообщения в контактной форме не подключены. Сторонние фотографии используются временно для визуального прототипа, не для коммерческого использования.
