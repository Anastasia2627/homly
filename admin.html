Бонусна програма

Усі бонуси нараховує сервер. За реєстрацію — один раз після підтвердження пошти; до дня народження — один раз на рік після першої оплаченої покупки, якщо дата збережена понад 30 днів тому. Нарахування та списання працюватимуть при оплаті лише після підключення monobank і перевірки тестових платежів.

Підключення сервісів

HOMLY перевіряє лише наявність ключів на сервері, але не показує їх і не вважає платіж чи лист перевіреним без тесту. API-ключі додавай тільки в Supabase → Edge Functions → Secrets, не в GitHub.

Що потрібно підключити

Нова пошта: отримати ключ у бізнес-кабінеті → додати NOVA_POSHTA_API_KEY.

Resend: підтвердити домен, створити ключ → RESEND_API_KEY, HOMLY_EMAIL_FROM, за потреби HOMLY_OWNER_EMAIL. Для листів авторизації окремо налаштувати SMTP у Supabase Auth.

Telegram: створи бота через BotFather → HOMLY_TELEGRAM_BOT_TOKEN та HOMLY_TELEGRAM_CHAT_ID. Спочатку надішли повідомлення боту, щоб він міг відповідати.

Search Console: додати сайт та відправити sitemap.xml.

Google Merchant Center: підтвердити магазин. XML-фід merchant-feed.xml з'явиться лише після публікації товарів із реальними фото.

Google Analytics, Clarity, Meta Pixel, Sentry: публічні ID/DSN вводяться у вкладці «Аналітика»; код працює тільки після згоди на cookies.

Доступність сайту: погодинну базову перевірку додано до GitHub Actions. Для незалежних сповіщень можна створити монітор у UptimeRobot.

Не надсилай секретні API-ключі у чат. Тексти вище — інструкції підключення, не підтвердження, що сервіси вже працюють.

Аналітика та реклама

Додай ID потрібних інструментів. Сайт завантажує їх лише після згоди відвідувача. Паролі й рекламні токени тут не потрібні.
