# HOMLY — creative shop

Нова редакційна концепція інтернет-магазину HOMLY, створена з чистого аркуша.

## Перегляд

Сайт — статичний. Достатньо відкрити `index.html` у браузері або запустити локальний сервер. На GitHub Pages автоматично публікується гілка `main`.

## Сторінки

- `index.html` — головна з анімованими блоками, асиметричною колекцією, розпакуванням і закріпленим фото процесу;
- `catalog.html` — каталог із категоріями, пошуком і сортуванням;
- `product.html?id=bag` — картка товару;
- `favorites.html` — обрані товари;
- `cart.html` — кошик;
- `about.html` — про HOMLY;
- `contacts.html` — контакти та відповіді на запитання.

## Анімації

Кожен блок із атрибутом `data-reveal` відкривається **тільки в момент появи в області перегляду** через `IntersectionObserver`. Заголовки, фото, товари та кроки мають окремі тригери. Рух фото при прокрутці реалізований через `requestAnimationFrame`. Якщо ввімкнено `prefers-reduced-motion`, контент показується без анімацій.

## Перед запуском продажів

Це демонстраційний фронтенд: товари, ціни та зображення — тимчасовий контент, не підтверджений асортимент HOMLY. Потрібно замінити їх реальними фотографіями, комплектацією, цінами й контактами; підключити оформлення, оплату та доставку. Кошик і обране працюють локально в браузері. Не використовуйте демонстраційні зображення в комерційних матеріалах без дозволу правовласників.

Чисті HTML, CSS та JavaScript. Дві гарнітури з підтримкою української: Onest та Nunito. Основні кольори HOMLY: `#EDEAF3`, `#AAB8E9`, `#A8174E`.
