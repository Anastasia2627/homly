# HOMLY — Motion Store

Анімаційний прототип інтернет-магазину DIY-наборів HOMLY.

## Запуск

Відкрийте `index.html` у браузері. Сторінки працюють без Node.js та сервера. Для завантаження шрифтів потрібне підключення до інтернету.

## Сторінки

- `index.html` — головна з анімаціями при прокрутці.
- `catalog.html` — категорії, пошук, сортування.
- `product.html?id=bag` — картка товару.
- `favorites.html` — улюблені товари.
- `cart.html` — кошик та кількість товарів.
- `about.html` — про бренд.
- `contacts.html` — контакти та FAQ.

## Демоверсія

Фотографії, описи та ціни демонстраційні. Кошик та улюблене зберігаються локально у браузері. Реальна оплата, відправлення замовлень і контактна форма ще не підключені. Перед запуском замініть дані товарів на підтверджені.

## Стиль

Fredoka + Nunito. Головні кольори: `#A8174E`, `#AAB8E9`, `#EDEAF3`. Анімації враховують налаштування `prefers-reduced-motion`.
